# DocDiary for iOS

DocDiary supports appointment, patient, prescription and authorized centre administration workflows. See [the Mac release guide](START_HERE_BN.md), [device acceptance checklist](docs/ACCEPTANCE_CHECKLIST.md) and [App Store Connect draft](docs/APP_STORE_CONNECT.md).

Open the included `ios/Runner.xcworkspace` after running `flutter pub get`. Build from `DocDiary_iOS`. The sibling `Archive` folder holds old patch records, rollback ZIPs and standalone previews.
